# Resumo – Aula 1: O que é um Banco de Dados?

Um Banco de Dados é uma forma de armazenar e organizar informações para que elas possam ser consultadas e utilizadas de maneira eficiente.

Antes dos computadores, as informações eram armazenadas principalmente em papel, organizadas em registros, pastas e arquivos. Com o surgimento dos computadores, os dados passaram a ser armazenados digitalmente.

Inicialmente, eram utilizados arquivos sequenciais, nos quais os dados eram armazenados em uma sequência e precisavam ser percorridos até encontrar a informação desejada. Depois surgiram os arquivos de acesso direto, que permitiam localizar os dados de forma mais rápida.

Com o aumento da quantidade de informações, surgiram os primeiros sistemas de banco de dados. Foram desenvolvidos diferentes modelos para organizar os dados, como o modelo hierárquico e o modelo em rede. Mais tarde surgiu o modelo relacional, que organiza as informações em tabelas e permite estabelecer relações entre elas.

Para trabalhar com um banco de dados é utilizada a SQL (Structured Query Language), uma linguagem usada para enviar comandos ao banco e consultar ou manipular informações.

Existem vários sistemas de gerenciamento de bancos de dados, como Oracle, IBM DB2, Microsoft SQL Server, MySQL, MariaDB, Firebird e PostgreSQL. O MySQL é um dos sistemas utilizados para trabalhar com bancos de dados.

Em resumo, a aula apresenta a evolução do armazenamento de dados, desde os registros em papel até os modernos bancos de dados, além de introduzir os modelos de organização, a linguagem SQL e o MySQL.
