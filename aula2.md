# Aula 2 - Instalação do MySQL Workbench

## Introdução

Nesta aula será realizada a instalação do MySQL Workbench no computador.

O MySQL Workbench é uma ferramenta gráfica utilizada para trabalhar com bancos de dados MySQL, permitindo criar, editar e administrar bancos de dados e executar comandos SQL.

## 1. Download

Primeiramente, acesse o site oficial do MySQL Workbench:

https://dev.mysql.com/downloads/workbench/

Na página de download, selecione a versão compatível com o sistema operacional utilizado.

Neste tutorial, será utilizada a versão para Windows.

## 2. Instalação

Após realizar o download, execute o arquivo de instalação do MySQL Workbench.

Na tela inicial do instalador, siga as instruções apresentadas.

Aceite os termos de licença e avance pelas etapas da instalação.

![Instalação do MySQL Workbench](imagem-instalacao.png)

Aguarde enquanto os arquivos necessários são instalados no computador.

## 3. Finalização

Após a instalação, abra o MySQL Workbench pelo menu Iniciar do Windows.

Ao abrir o programa, será apresentada a tela inicial do MySQL Workbench.

![Tela inicial do MySQL Workbench](mysql-workbench.png)

## 4. Utilização

Na tela inicial do MySQL Workbench é possível criar e acessar conexões com servidores MySQL.

Também é possível utilizar ferramentas para desenvolver comandos SQL, criar modelos de bancos de dados e realizar tarefas de administração.

## Conclusão

O MySQL Workbench foi instalado corretamente e está pronto para ser utilizado nas próximas atividades do curso.

A ferramenta será utilizada para trabalhar com bancos de dados MySQL e executar comandos SQL.
